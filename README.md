# 🧹 BB Cleanup Manager

Менеджер очистки для **SillyTavern** — находит старые короткие чаты и неиспользуемые лорбуки, помогает проверить их и безопасно удалить. Ничего не удаляет автоматически: решение всегда остаётся за пользователем.

---

## ✨ Что умеет

### 💬 Старые чаты

- Ищет личные и групповые чаты старше выбранного количества дней.
- Учитывает максимальное количество сообщений: например, старше `30 дней` и не больше `5 сообщений`.
- Никогда не предлагает удалить открытый сейчас чат.
- Показывает персонажа или группу, название файла, дату, количество сообщений и размер.

### 📚 Неиспользуемые лорбуки

- Ищет лорбуки без активных привязок.
- Проверяет глобальные, персонажные, персональные и чатовые подключения.
- Учитывает дополнительные привязки расширений и **SillyTavern Memory Books**.
- Позволяет выбрать Memory Book, который освободится только после удаления всех связанных чатов-кандидатов.
- Повторно проверяет привязки непосредственно перед удалением.

### 🧭 Удобный просмотр

- Открывает результаты в отдельном большом окне.
- Разделяет чаты и лорбуки по вкладкам.
- Показывает результаты адаптивными карточками вместо тесной таблицы.
- Поддерживает поиск, сортировку и массовый выбор видимых элементов.
- Перестраивает карточки и кнопки в одну колонку на узких мобильных экранах.
- Позволяет открыть чат или лорбук для проверки перед очисткой.

### 🛟 Бэкап и удаление

Перед удалением можно выбрать один из двух вариантов:

- **Создать ZIP и удалить** — сначала скачивает архив с выбранными чатами и лорбуками.
- **Удалить без бэкапа** — сразу удаляет выбранное, если копия уже есть или данные точно не нужны.

ZIP также можно скачать отдельно, не удаляя данные. После очистки менеджер повторно сканирует SillyTavern и показывает фактический результат.

---

## ⚙️ Как определяются кандидаты

| Тип | Условие |
|---|---|
| 💬 **Чат** | Старше заданного срока и содержит не больше заданного количества сообщений |
| 📖 **Лорбук** | Не найдено ни одной активной привязки |
| 🧠 **Memory Book** | Связан только с чатами-кандидатами и станет свободным после их удаления |

Порог возраста настраивается от `1` до `3650` дней, а количество сообщений — от `0` до `1000`. По умолчанию используются `30 дней` и `5 сообщений`.

## 🚀 Использование

1. Откройте панель расширений и найдите **BB Cleanup Manager**.
2. Укажите возраст чатов и максимальное количество сообщений.
3. Нажмите **Сканировать**.
4. В открывшемся окне проверьте кандидатов, используйте вкладки, поиск и сортировку.
5. Отметьте нужные элементы.
6. Скачайте ZIP отдельно либо нажмите **Удалить** и выберите способ очистки.

## 📦 Установка

1. Откройте SillyTavern.
2. Перейдите в `Расширения → Установить расширение`.
3. Вставьте ссылку на репозиторий:
   ```
   https://github.com/maxkara14/BB-Cleanup-Manager
   ```
4. Перезагрузите страницу SillyTavern.
5. Откройте панель расширений — там появится **BB Cleanup Manager**.

## 🔒 Безопасность

- Расширение только показывает кандидатов и не запускает очистку самостоятельно.
- Перед удалением всегда отображается отдельное подтверждение.
- Удаление без ZIP помечено как опасное действие и не может быть отменено средствами SillyTavern.
- Активный чат защищён от удаления.
- Привязки лорбуков проверяются повторно непосредственно перед операцией.

Даже хороший фильтр не знает ценность вашего сюжета. Просматривайте выбранные элементы и храните ZIP, пока не убедитесь, что очистка прошла правильно.

---

## 📌 Ограничения

- Текущая версия очищает чаты и лорбуки. Поиск неиспользуемых изображений пока не реализован.
- Браузер должен разрешать скачивание файлов, чтобы сохранить ZIP-бэкап.
- Удаление выполняется через штатные механизмы SillyTavern и является необратимым без сохранённой копии.
